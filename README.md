# Datheon_Python_Programming_Internship
Overview
This repository contains four Python projects completed as part of my Datheon internship tasks. The projects demonstrate Python fundamentals, input handling, file processing, CSV operations, regular expressions, and rule-based responses.
Projects
Task 1: Hangman Game
A terminal-based word-guessing game. The player guesses letters in a hidden word and tries to solve it before running out of attempts.

Features
- Random word selection
- Displays guessed letters and remaining attempts
- Handles repeated guesses
- Reports win or loss
Run
python hangman.py
Task 2: Investment Portfolio Tracker
A command-line tool that accepts stock ticker symbols, purchase prices, and share quantities. It reads current prices from a local CSV file, calculates portfolio values and gain/loss, and writes a summary CSV.

Features
- Accepts ticker, buy price, and quantity
- Reads sample current prices from sample_prices.csv
- Calculates holding value and percentage gain/loss
- Exports results to portfolio_summary.csv
- Handles tickers not found in the sample price data
Run
python portfolio.py
Important: This version uses sample prices stored locally; it does not retrieve live market prices and is not financial advice. Keep portfolio.py and sample_prices.csv in the same folder. The CSV header should be exactly ticker,current_price.
Task 3: Desktop File Organizer
A utility that sorts files in a selected folder into subfolders based on file extensions.

Features
- Categorizes supported files into folders such as Documents, Images, Videos, Archives, Code, and Others
- Creates category folders automatically
- Avoids overwriting files with duplicate names
- Prints a summary of moved and failed files
Run
python organizer.py
When prompted, enter the full path to the folder you want to organize. Test with copies of files in a separate test folder first. Do not select the main project folder, because files may be moved into category folders.
Task 4: Rule-Based Customer Support Chatbot
A terminal chatbot that uses keyword matching and regular expressions to answer common customer-support questions.

Features
- Responds to greetings
- Handles sample questions about business hours, products, prices, delivery, returns, and contact information
- Uses a fallback response for unrecognized questions
- Exits when the user enters bye, exit, or quit
Run
python chatbot.py
Note: The chatbot uses example responses stored in the Python code. Its business hours and support answers are sample information, not verified details for a real company.

Requirements
- Python 3
- No third-party packages are required by these implementations; they use Python standard-library modules.
Getting Started
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the relevant program using the commands listed under each task.
5. Follow the prompts displayed in the terminal.
Testing
Test each project before submission:
- Hangman: Check correct guesses, incorrect guesses, repeated letters, win, and loss.
- Portfolio Tracker: Test a ticker included in sample_prices.csv, an unknown ticker, and confirm the output CSV is created.
- File Organizer: Test using disposable sample files in a separate folder and confirm they are moved to the expected categories.
- Chatbot: Test greetings, each supported FAQ category, an unknown question, and all exit commands.
